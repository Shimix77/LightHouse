# LightHouse

LightHouse is a macOS-first professional desktop application for designing and running DMX lighting shows from a visual 2D stage layout.

The project is currently in the architecture and MVP definition phase. The core is being designed for later Windows support and keeps the user interface fully separated from real-time DMX output.
